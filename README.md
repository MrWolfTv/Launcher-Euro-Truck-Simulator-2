## 🚛 À quoi sert ce Launcher ?
Le **ETS2 Convoi Launcher** est un outil tout-en-un conçu pour simplifier la vie des chauffeurs sur Euro Truck Simulator 2. Au lieu d'ouvrir manuellement chaque application nécessaire pour vos convois, ce launcher centralise tout en un seul clic.

Il permet de lancer simultanément :
*   **TruckersMP** (Pour le multijoueur)
*   **TrucksBook** (Pour le suivi kilométrique)
*   **Trucky** (Pour l'overlay et les infos en temps réel)
*   **PickUp** (Ou toute autre application de suivi VTM)

## 🛠️ Fonctionnalités principales
*   **Démarrage Express** : Ferme les instances existantes et relance tout proprement.
*   **Tout Arrêter** : Un bouton d'urgence pour fermer proprement tous les logiciels liés au jeu.
*   **Configuration Personnalisée** : Modifiez les chemins de vos applications directement via l'interface. Vos réglages sont sauvegardés automatiquement dans votre dossier `AppData`.
*   **Interface Moderne** : Design épuré avec fond d'écran intégré (système Base64) et bordures blanches élégantes.
*   **Léger & Autonome** : Une fois converti en `.exe`, il ne nécessite aucune installation.

## 🚀 Installation et Utilisation

1.  Lancez le fichier `ETS2_Launcher.exe`.
2.  Lors du premier lancement, cliquez sur **Paramètres**.
3.  Sélectionnez les fichiers exécutables (`.exe`) de vos logiciels de convoi.
4.  Cliquez sur **Sauvegarder**.
5.  Revenez au menu principal et cliquez sur **Lancer les applications**.

## 🛡️ Note sur les Antivirus
Comme ce programme est un script PowerShell converti en exécutable par un utilisateur indépendant, il est possible que Windows Defender affiche une alerte **SmartScreen**.
*   **Pourquoi ?** Le fichier n'est pas signé numériquement (ce qui coûte très cher).
*   **Solution** : Cliquez sur *Informations complémentaires* puis sur *Exécuter quand même*. Le code ne fait qu'exécuter des programmes déjà présents sur votre ordinateur.
